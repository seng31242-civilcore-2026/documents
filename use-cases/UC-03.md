# Use Case: UC-03
**Use Case ID:** UC-03
**Use Case Name:** Submit Asset Request
**Actor(s):** Supervisor (Mobile App User)

**Preconditions:** 
* The Supervisor is logged in and assigned to the active project.

**Postconditions – Success:** 
An asset request is logged as "Pending" and the Manager is notified.

**Postconditions – Failure:** 
The request is not submitted due to missing required fields.

**Main Flow:**
1. The Supervisor navigates to the "Asset Requests" tab.
2. The Supervisor selects the material or equipment needed for the next day.
3. The Supervisor enters the required quantity.
4. The Supervisor specifies the needed date.
5. The Supervisor submits the request.
6. The System saves the request with a "Pending" status and triggers an alert for the Manager.

**Alternative Flow 1 (Offline Request):**
* At step 5: If offline, the system caches the request locally and syncs it when the connection is restored, alerting the Manager upon successful sync.
