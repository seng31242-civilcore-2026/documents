# Use Case: UC-02
**Use Case ID:** UC-02
**Use Case Name:** Setup Project and Import BOQ
**Actor(s):** Manager (Web App User)

**Preconditions:** 
* The Manager is logged into the web application.

**Postconditions – Success:** 
A new project is created with assigned supervisors, a Gantt-style schedule, and the Bill of Quantities (BOQ) is successfully converted into trackable tasks.

**Postconditions – Failure:** 
The project is not saved. An error message is displayed to the Manager detailing the validation or formatting failure (e.g., unsupported BOQ file format).

**Main Flow:**
1. The Manager clicks "Create New Project".
2. The Manager enters basic project details (name, location, start and end dates).
3. The Manager assigns one or more Supervisors to the project.
4. The Manager creates a simple Gantt-style schedule with planned start and end dates per activity.
5. The Manager selects "Import BOQ" and uploads the BOQ document (or chooses to manually enter work items).
6. The System processes the BOQ and converts each line item into a trackable system "Task" containing the planned quantity, unit, and rate.
7. The Manager clicks "Save Project".
8. The System confirms the project is active.

**Alternative Flow 1 (Manual BOQ Entry):**
* At step 5: If the Manager chooses manual entry, the system displays a dynamic form.
* The Manager manually inputs the work item name, planned quantity, unit, and rate for each task.

**Business Rules:**
* **BR-03:** A project cannot be activated without at least one assigned Supervisor and one BOQ item.
