**Use Case ID:** UC-04
**Use Case Name:** Review Asset Request
**Actor(s):** Manager (Web App User)

**Preconditions:** 
* There is at least one "Pending" asset request from a Supervisor.

**Postconditions – Success:** 
The asset request status is updated to "Approved" or "Rejected", and the Supervisor is notified.

**Main Flow:**
1. The Manager receives an alert and navigates to the dashboard.
2. The Manager opens the pending Asset Request.
3. The Manager reviews the requested item, quantity, and needed date.
4. The Manager clicks "Approve".
5. The System updates the request status to "Approved" and notifies the Supervisor.

**Alternative Flow 1 (Reject Request):**
* At step 4: The Manager clicks "Reject" and optionally adds a reason.
* The System updates the status to "Rejected" and alerts the Supervisor.
