**Use Case ID:** UC-06
**Use Case Name:** View Owner Dashboard
**Actor(s):** Owner (Web App User)

**Preconditions:** 
* The Owner is logged in.

**Postconditions – Success:** 
The Owner views a read-only, cross-project summary.

**Main Flow:**
1. The Owner accesses the main dashboard.
2. The System displays a high-level summary across all active projects.
3. The Owner selects a specific date or date range.
4. The System filters and displays progress for that period.
5. The System displays a cost versus budget overview.
6. The System displays active alerts for project delays or budget overruns.

**Business Rules:**
* **BR-04:** The Owner role has strictly read-only permissions and cannot modify tasks, schedules, or BOQs.
