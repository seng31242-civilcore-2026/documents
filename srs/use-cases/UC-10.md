# Use Case: UC-10
**Use Case ID:** UC-10
**Use Case Name:** Sync Offline Data
**Actor(s):** System / Supervisor (Mobile App User)

**Preconditions:** 
* The Supervisor has saved data (reports, asset requests, issues) locally on the device while without an internet connection.

**Postconditions – Success:** 
All locally cached data is uploaded to the central database and removed from the pending local cache.

**Main Flow:**
1. The mobile device detects a restored internet connection.
2. The System automatically triggers a background sync process.
3. The System pushes the locally cached daily reports, asset requests, and material logs to the database.
4. The Database validates and saves the entries.
5. The System clears the local pending cache and displays a "Sync Complete" notification to the Supervisor.

**Alternative Flow 1 (Sync Failure/Conflict):**
* At step 4: If validation fails or the connection drops again, the data remains safely in the local cache. The System alerts the Supervisor that the sync failed and will automatically retry later.
