# Use Case: UC-01
**Use Case ID:** UC-01
**Use Case Name:** Submit Daily Report
**Actor(s):** Supervisor (Mobile App User)

**Preconditions:** 
* The Supervisor is logged into the mobile application.
* The Supervisor is assigned to an active project that has been set up with a Bill of Quantities (BOQ). 
* The mobile device has sufficient local storage for caching data and photos.

**Postconditions – Success:** 
The daily report (including tasks, materials, labour, weather, and photos) is successfully saved and synchronized with the central database. The Manager can view the report on the web dashboard.

**Postconditions – Failure:** 
The report is not submitted. If the failure is due to validation errors, an error message is displayed. If due to connectivity issues, the data remains safely cached locally.

**Main Flow:**
1. The Supervisor clicks "Create Daily Report" from the mobile app dashboard.
2. The System retrieves and displays the active tasks linked to the project's BOQ work items.
3. The Supervisor selects the completed tasks and enters the completed quantities.
4. The Supervisor logs the materials and equipment used for the day.
5. The Supervisor inputs the number of workers on site (skilled and unskilled) and the total hours worked.
6. The Supervisor selects the day's weather condition.
7. The Supervisor captures or uploads site photos, which the system automatically geo-tags.
8. The Supervisor logs any observed issues or problems on the site.
9. The Supervisor clicks "Submit Report".
10. The System validates the inputs, synchronizes the data with the database, and displays a success confirmation message.

**Alternative Flow 1 (Offline Mode):**
* At step 9: If the device does not have an active internet connection, the system bypasses immediate synchronization. 
* The system saves the report data locally on the device and displays a message stating "Saved Offline. Will sync when connection is restored."
* Once internet connectivity is detected, the system automatically synchronizes the cached report in the background.

**Alternative Flow 2 (Incomplete Data):**
* At step 10: If mandatory fields (e.g., tasks completed or labour hours) are missing, the system highlights the missing fields and prompts the Supervisor to complete them before allowing submission.

**Business Rules:**
* **BR-01:** The daily report workflow must be streamlined enough that a Supervisor can complete it in under 5 minutes.
* **BR-02:** Tasks reported must correspond strictly to the imported BOQ line items for that specific project.
