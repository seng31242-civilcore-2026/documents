# Use Case: UC-08
**Use Case ID:** UC-08
**Use Case Name:** Report Site Issue
**Actor(s):** Supervisor (Mobile App User), Manager (Web App User)

**Preconditions:** 
* The Supervisor identifies a problem/snag on site.

**Postconditions – Success:** 
An issue is logged as "Open", and later marked as "Resolved" by a Manager.

**Main Flow:**
1. The Supervisor clicks "Report Issue" in the mobile app.
2. The Supervisor types a description of the problem.
3. The Supervisor captures a photo of the issue.
4. The System geo-tags the photo.
5. The Supervisor submits the issue.
6. The System sets the issue status to "Open" and notifies the Manager.
7. (Manager Flow) The Manager views the issue on the web dashboard.
8. The Manager resolves the problem on-site and clicks "Close Issue".
9. The System updates the status to "Resolved".
