# Use Case: UC-05
**Use Case ID:** UC-05
**Use Case Name:** View Progress Dashboard
**Actor(s):** Manager (Web App User)

**Preconditions:**
* The project has an imported BOQ and Supervisors have submitted daily reports.

**Postconditions – Success:**
The Manager views up-to-date project metrics calculated against the BOQ.

**Main Flow:**
1. The Manager navigates to the Project Dashboard.
2. The System calculates the overall project completion percentage by comparing the reported daily task quantities against the planned BOQ quantities.
3. The System displays the calculated completion percentage.
4. The System displays materials used versus the budget.
5. The System displays the total labour hours logged per day.
6. The System lists any pending daily reports awaiting review.
